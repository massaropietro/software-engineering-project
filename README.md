# Progetto Ingegneria del Software: Analisi dei Mutanti Equivalenti

Questo repository ospita il progetto universitario per l'esame di **Ingegneria del Software**. La ricerca si focalizza sulla **Mutation Testing**, con particolare attenzione all'identificazione e alla gestione dei **mutanti equivalenti** all'interno del codice sorgente.

## 🔬 Obiettivo del Progetto
L'obiettivo principale è analizzare come i mutanti equivalenti (mutazioni del codice che non ne alterano il comportamento osservabile) influenzino il *mutation score* e come possano essere gestiti per migliorare l'efficacia delle suite di test.
